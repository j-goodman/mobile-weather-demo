# Mobile Weather Demo

A simple Expo/React Native app to search for a city's current weather and upcoming
forecast using OpenWeather, with light and dark themes.

## Get started

1. Run `npm install`.
2. Create `.env.local` with your OpenWeather API key:
   ```env
   EXPO_PUBLIC_OPENWEATHER_API_KEY=your_api_key
   ```
3. Run `npx expo start`, then open the app in Expo Go, a simulator, or the browser.
